# Workforce Analytics and Compensation Drivers

## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) in **R** on corporate workforce data to analyze compensation structures, department distribution, and performance tiers across a 10-employee sample cohort. It evaluates key drivers of employee salary using statistical summaries, categorical distributions, and linear regression analysis[cite: 2].

## 📊 Key Findings
- **Strong Seniority-Pay Correlation:** Pearson correlation coefficient ($r \approx 0.9913$) confirms a near-perfect positive linear relationship between years of experience and salary[cite: 2].
- **Compensation & Tenure:** Monthly salaries range from ₹32,000 (1 year experience) to ₹92,000 (9 years experience), with an average salary of ₹63,200[cite: 2].
- **Performance Breakdown:** 50% of the cohort fell into the 'High' performance tier, 30% 'Medium', and 20% 'Low'[cite: 2].

## 🛠️ Tech Stack & Tools
- **Language:** R[cite: 2]
- **Libraries/Methods:** Base R Graphics (`pie`, `barplot`, `plot`), Descriptive Statistics (`sd`, `var`, `cor`), Linear Modeling (`lm`)[cite: 2]
